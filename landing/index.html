🌐

PHP + Node.js Hosting

Multi-version PHP (7.4–8.4) with per-site FPM pools. Node.js with git-based deploy pipeline, releases, health checks & auto-rollback.

🔐

Free SSL, Automatically

Let's Encrypt certificates issued and renewed automatically. One click per site. HTTPS everywhere by default.

📁

Built-in File Manager

Browse, edit, upload and manage files directly from the browser. Full CRUD with a clean code editor. No FTP client needed.

✉️

Email + Webmail

Postfix + Dovecot + SnappyMail. Domain management, mailboxes, aliases, DKIM signing. Lightweight webmail included.

🔄

Git Auto-Deploy

Push to deploy. Webhook triggers build → release → health check. Rollback with one click if something breaks.

📦

Smart Backups

Scheduled backups with configurable scope (sites only, databases only, or everything). Retention policy. One-click restore.

🗄

Database Management

Create MariaDB databases, import/export SQL, manage users and passwords. One-click Adminer for advanced needs.

📜

.htaccess Compatible

Choose nginx for speed or Apache mode for .htaccess compatibility. Built-in converter for migrating existing rules.

🛡

Security First

Per-site Linux users, scrypt password hashing, optional TOTP 2FA, sudo whitelist architecture, audit logging.

Up and running in 5 minutes

One script. Fresh Ubuntu 24.04 or Debian 12. Done.

terminal
# Provision the server
scp -r nimbuspanel root@your-server:/root/
ssh root@your-server
cd nimbuspanel && bash provision/provision.sh
 
✓ nginx · PHP 8.2+8.3 · Node 22 · MariaDB
✓ SSL · Postfix · Dovecot · fail2ban
 
# Deploy the panel
bash scripts/deploy.sh
 
✓ Panel running at http://your-server-ip
✓ Set your domain + SSL from the Settings page
